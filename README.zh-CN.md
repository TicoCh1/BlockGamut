# BlockGamut

[English](README.md) · 简体中文

[打开网站](https://ticoch1.github.io/BlockGamut/) · [源代码](https://github.com/TicoCh1/BlockGamut)

BlockGamut 是 Minecraft Java 版方块的三维色彩与材质探索器。它将保留原版尺寸和纹理的方块模型排列在色彩空间中，帮助建造者比较配色、寻找相近材质、分析纹理变化，并查看不同正式版本中的方块外观。

网站完全在浏览器中运行，无需安装 Minecraft、登录账号、上传世界或连接后端。默认语言为英语，也支持简体中文。

项目作者：[TicoCh1](https://github.com/TicoCh1)。Minecraft 材质 © Mojang / Microsoft。

### 材质方差模式

任意色彩空间都能开启“材质方差”，按照纹理变化程度排列方块。统计统一使用由原始、未打光 UV 区域生成的 **六个 16×16 材质面，共 1536 个像素**。小区域循环补齐，大区域采用 BOX 降采样；同方向的不同区域合并到一个材质面，缺少的方向循环已有材质面。透明像素不贡献颜色权重，模型尺寸、面面积和重复几何不再增加统计权重。网站展示的原版纹理与模型尺寸保持不变。坐标轴采用固定对数比例，零值也具有有限位置；检查器显示未经对数变换的总体方差。色相方差使用最短圆弧距离，并排除无色像素。

## 三种排列方式

- **间隔**：保留原版模型尺寸，并留出至少一格空隙。
- **无间隙**：在整数格点上排列，预留模型实际占用的空间。
- **密铺**：每个显示材质至少保留一格，再用最接近的材质填充其他色域内格子。同一方块的多个实例共用选中状态。

改变设置时，方块使用同步曼哈顿路径移动。密铺只移动代表实例，其余填充通过淡入淡出替换。系统的“减少动态效果”偏好会关闭移动动画，并让模型转台默认暂停。

## 体素切片

无间隙或密铺模式下，点击“体素切片”打开可移动窗口。选择切片轴和位置，保留一侧体积或单层格子，也可以反转保留方向。色相类空间在关闭方差模式时还支持色相角和半径切片。

拖动窗口标题栏可移动窗口；聚焦拖动按钮后，也可以使用方向键移动，按住 Shift 进行一像素微调。位置滑块会同时更新二维纹理切片和三维切面。点击切片中的格子，会选中该方块的全部实例。

## 筛选与历史材质

“筛选”区域可以组合 Minecraft 版本、搜索、方差范围、几何类型、颜色来源、材质分组、不透明条件和群系染色条件。

当前资源覆盖 Mojang 官方版本清单中 **1.7.2 至 26.3 的 84 个 release 条目**，不包含快照。没有所展示材质变化的版本合并为 **31 组**，以最早版本命名，需要时添加 `+`。例如 **1.7.2+** 覆盖 1.7.2–1.7.10，界面会显示完整范围。初始选择最新的已收录版本；未来版本需要更新资源数据。

切换版本时，可用方块、原版纹理、模型、颜色和动画一起切换。旧版本使用旧材质。原版的大规模默认材质更新发生在 [Java 1.14](https://www.minecraft.net/en-us/article/village---pillage-out-java-)。

![最早版本组及其原始材质](media/screenshots/16-old-release.jpg)

“材质分组”按实际解析后的纹理集合和染色合并材质，优先使用完整立方体作为代表。颜色相近本身不会导致合并。关闭分组可以查看各个变体。几何筛选支持完整立方体、平面、实体／超尺寸预览和其他模型；颜色来源可以选择模型平均颜色或六个面的颜色。

![几何、表面与不透明条件的组合筛选](media/screenshots/17-filters.jpg)

### 方差范围

范围筛选使用 **当前所选色域的三个通道总体方差之和**。例如 Oklab 为 `Var(L) + Var(a) + Var(b)`，sRGB 为 `Var(R) + Var(G) + Var(B)`。标签、数值和范围随色域变化，并在当前页面会话中分别记住各色域的范围。范围筛选和方差坐标轴使用同一套 1536 像素标准化统计；在平均颜色视图和材质方差视图中均有效，不受颜色来源选择影响。上下限均包含在结果中。

同一条对数轨道上有 `‹│` 和 `│›` 两个滑块，端点读数是实际方差。拖动松开后应用筛选；方向键直接调整，Shift 加大步长，Page Up／Down 大幅调整，Home／End 移到边界。两个滑块不能交叉，重合时仍能分别操作。点击重置箭头恢复完整范围。

## 检查原版模型与收藏

检查器包含旋转模型预览、方块 ID、资源文件和变体、采样颜色、坐标或方差，以及五种代表表面颜色的比例。可以暂停／恢复转台，或点击“三维聚焦”将相机移到所选方块附近。

模型保留原版尺寸和透明度，支持非立方体、交叉植物平面、多部件模型、完整高植物及特殊渲染器的静态预览。材质动画保留原版帧序列、持续时间和插值；末地传送门使用分层动态预览。

### 黑名单

点击检查器中的“加入黑名单”，即可从普通视图和“我的收藏”中隐藏所选方块。开启材质分组时，操作包含该材质组展示的全部变体，避免其他相同材质变体立即替代被隐藏的代表。黑名单在材质分组前生效，与其他筛选条件取交集。

将几何筛选切换到“我的黑名单”，选择其中的方块，再点击“移出黑名单”即可恢复。该视图仍受搜索和方差范围等条件影响；如果找不到条目，可以先重置筛选。重置筛选不会清空黑名单。黑名单与收藏一样保留在当前页面会话中，刷新页面后清空。

## 资源结构与限制

资源采用增量存储：相同纹理像素只保存一次，每个材质版本组记录相对于上一组变化的目录条目、模型和动画信息。3,569 个独立纹理块打包在七张图集中。没有变化的版本不会再复制一套材质。运行时会缓存重建后的版本数据。

颜色与方差描述原始纹理像素，不代表游戏中的光照效果。五种代表颜色仅用于展示，不参与方差计算。每种方块采用一个代表放置状态；特殊渲染器使用关闭／静止姿态、默认皮肤及无额外装饰的旗帜或陶罐。世界光照、粒子、动态方块实体和自定义方块数据不在预览范围内。不可见方块保留在目录中，不虚构表面颜色；空气种类和物品展示框不加入放置方块图谱。

三维场景需要支持 WebGL 的现代浏览器。密铺模式可能比无间隙模式消耗更多资源，尤其是大型 RGB 色域。

## 本地运行

使用 **Node.js 22 或更新版本**和 npm：

```sh
npm ci
npm run dev
```

打开 `http://127.0.0.1:5190/`。生产构建与预览：

```sh
npm run build
npm run preview
```

预览地址为 `http://127.0.0.1:4190/`。静态网站输出到 `dist/`。

## 静态部署

Vite 使用相对资源路径，构建结果可部署在仓库子目录中，无需服务器 API。[GitHub Pages 工作流](.github/workflows/pages.yml)会在 `main` 更新后安装锁定依赖、构建网站并发布 `dist/`。

Fork 后，在仓库 Pages 设置中选择 **GitHub Actions** 作为来源。其他静态网站服务也可以直接托管 `dist/` 的内容。

公开仓库保留网站代码、运行资源、构建支持、许可证及图文 README。本地开发记录、私人配置、凭据、缓存和生成的构建目录不上传。
